# samples

`tools/make_form.py`로 다시 만들 수 있다. 정답표는 `_truth.json`이고, `tools/check_extract.py`로 채점한다.

## 반장_테스트/ — 작업반장 시점 테스트 (지금 쓰는 것)

종류별 2건씩 10건이다. 모두 안전부서 제출용 낱장이다. 데이터는 `tools/foreman_permits.py`에 있다.

| 형 | 내용 |
|---|---|
| A | 실물 0453·0400의 작성 습관을 넣었다. 08:00~16:59를 여러 날 복사, 팀 이름이나 공장·BAY까지만 적은 장소, 호선·병행여부 빈칸, 짧은 위험요소, 블록 나열 |
| B | 꼼꼼하게 쓴 것. 핵심 질문이 거의 없어야 정상이다(통제 범위 정도) |

파일마다 나와야 할 질문(핵심·선택·추정)이 정해져 있고, `tools/check_questions.py`가 확인한다.

## 시연/ — 작업쌍 시나리오 (나중에 안전관리자 시점에서 씀)

대조립 합성 허가 신청 5건을 한 건씩 나눈 파일이다. 모두 **안전부서 제출용**이고, 작업일은 2026-10-27, 장소는 대조립21공장 3BAY다.

| 파일 | 종류 | 심어 둔 문제 (팀 조사자료 위험쌍 P01~P05) |
|---|---|---|
| `0611_화기.pdf` | 화기 | E41P 블록 외판 절단·용접. 같은 블록에서 0612 배관 진입(P01), 0614 반출 인양(P05)과 시간이 겹침 |
| `0612_밀폐.pdf` | 밀폐 | E41P 내부 배관 진입. 사람이 안에 있는 블록을 0614가 인양함(P02) |
| `0613_고소.pdf` | 고소 | 병행여부 빈칸. 같은 3BAY에서 0614 인양 경로와 겹침(P03) |
| `0614_중량물인양.pdf` | 중량물인양 | 병행여부 빈칸. 수리 중인 크레인 OH-21-03으로 인양함(P04) |
| `0615_정전LOTO.pdf` | 정전·LOTO | OH-21-03 제어반 수리인데 병행여부를 N으로 적음(P04) |

- 앱에 내장하지 않는다. 시연 때 웹 첫 화면에서 종류를 고르고 이 파일을 올린다.
- 도커 이미지에는 `samples/` 전체가 들어가지 않는다.

## 작업계획서/ — 일상작업 (허가서와 함께 첫 화면 3번 칸에 올림)

입력 단위는 계획서 1건 = 2쪽이다. 쪽마다 찍힌 문서번호로 한 건씩 묶는다.

| 파일 | 내용 |
|---|---|
| `합성_작업계획서_6사12건24쪽_R05.pdf` | 팀이 만든 원본 합성 작업계획서 12건(6개 업체). 손대지 않는다 |
| `낱건_12건/` | 원본을 건마다 2쪽씩 나눈 것 |
| `정리본_12건/`, `정리본_6사12건24쪽.pdf` | 같은 값을 정리한 양식으로 다시 그린 것(제목·값 세로 가운데, 단일 선, 같은 틀 너비, 공정 단계도 표) |
| `빈양식/` | 정리한 양식의 업체별 빈 양식 6종(현대힘스, 삼녹, 세진중공업, 한국카본, 동화엔텍, 동성화인텍)과 6사 묶음 |

- 읽기: `server/workplan.py`. 원본 양식과 정리한 양식을 모두 읽는다.
- 수정본과 정리한 양식 그리기: `server/workplan_pdf.py`. `tools/make_workplan_forms.py`가 정리본·빈 양식을 다시 만들고 다시 읽어 값을 비교한다.
- `tools/stress_workplan.py`: 빈 양식에 무작위 값을 채워 7가지 방식으로 확인한다(수정본 다시 읽기 포함).

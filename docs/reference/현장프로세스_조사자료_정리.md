## 0. 한눈에 보기

1. **흐름:** 작업반장이 **전날 15시까지** 「안전부서 제출용」 허가서에 **체크리스트를 동봉**해 전산에 올린다. 안전팀이 검토한 뒤 전산승인하면 「현장 게시용」 허가서가 출력된다.
2. **허가구분 2가지:**
   - **안전현장허가**는 작업 당일 안전관리자의 **안전대면허가**(현장 확인·교육·서명)가 더 필요하다.
   - **전산허가**는 전산승인으로 끝난다.
3. **허가서 종류는 5가지다.** 밀폐·화기·고소·중량물인양·정전(LOTO)이다. 양식은 같고, 「추가정보」 칸의 **종류별 전용 체크 12항목**만 다르다.
4. **현장 상황:** 안전팀에는 하루 **40~50건**이 올라온다. 그래서 반장이 체크한 위험 포인트만 보고 넘기고, 꼼꼼히 보지는 못한다(멘토 발언). 이것이 croScan이 들어갈 자리다.
5. **조사 대상 작업:** 대조립 **일상 6종(R1~R6)**과 **비일상 5종(N1~N5)**이다. 비일상 5종은 위 허가서 5종과 하나씩 짝이 된다.
6. **위험쌍 45개를 정리했다.**
   - 일상×비일상 30칸, 비일상×비일상 15종이다.
   - 쌍마다 성립 조건, 위험한 시점, 확인할 정보, 조치, 사고 근거가 있다.
   - 이 자료가 그대로 croScan의 **위험조합 규칙표**와 **확인 질문 템플릿**이 된다.
7. **시연 데이터 후보:** 합성 허가서 5건과 충돌쌍 5개(P01~P05)가 있다. 조정 전에는 5쌍이 모두 겹치고, 조정 후에는 겹침이 0이다.

## 1. 등장인물과 서류

| 구분 | 뜻 |
|---|---|
| 작업반장(조장 포함) | 현장에서 작업자에게 지시한다. 허가서를 신청한다. 원문에서는 "보통 조장·반장들이 신청" |
| 안전관리자(안전팀) | 반장이 낸 허가서를 검토하고 최종 승인한다. 안전대면허가란에 서명한다 |
| 안전요원 | 허가서 하단 「작업허가 전 추가조치 요청사항」을 **수기로** 적는다. 원문 표기는 "안전요원 작성" |
| 안전부서 제출용 허가서 | 비일상작업을 하려고 반장이 제출하는 서류 |
| 현장 게시용 허가서 | 안전부서가 승인한 뒤 현장에 붙이는 서류. 안전대면허가 행이 없다 |
| 체크리스트 | 반장이 허가서와 **함께 동봉해** 보낸다. 허가서 안의 위험 포인트 체크를 가리키는 것으로 보인다 |
| PTW(Permit To Work) | 허가를 받아야만 할 수 있는 작업. 대상 기준은 공개되어 있지 않다 |

## 2. 현장 전산 프로세스 (As-Is)

```
[전날 15:00까지]  작업반장 ── 안전부서 제출용 허가서 + 체크리스트 ──▶ 전산 시스템
                                                                    │
[검토]            안전팀(안전관리자): 체크리스트 검토 → 누락 위험 보완·추가조치 요구
                                       → 혼재작업 조정(시간·일정) → 전산승인
                                                                    │
                  현장 게시용 허가서 출력 ◀──────────────────────────┘
                                                                    │
[작업 당일]       안전현장허가이면: 안전관리자 현장 확인·교육 → 안전대면허가 서명 + 추가조치 수기
                  작업 시작 전: 반장이 「현장 안전조치」·「추가정보」 체크 (사전 작성 금지)
```

### 반장이 넣는 정보 5묶음 (원문 3쪽 표)

| 묶음 | 내용 | 작성 시점·주체 |
|---|---|---|
| 1. 작업내용 | 작업명·상세, 호선/공사번호, 대상 블록·설비, 작업표준 번호 | 전날 신청 시, 반장 등 작업부서 |
| 2. 장소·일시 | 상세 위치(공장·BAY·칼럼·블록), 일자, 시작·종료, 주간·야간 | 전날 신청 시 |
| 3. 부서·담당자 | 부서·협력업체, 책임자·관리자 이름·연락처·TRS, 인원, 신청자 | 전날 신청 시 |
| 4. 유해위험요소·추가전달사항 | 예상 위험, **알고 있는 병행작업**, 주의사항·조치 계획, 밀폐·가스 사용 등 | 전날 신청 시 |
| 5. 현장 안전조치·추가정보 체크리스트 | 경고표지·통행로·구역통제·소화장비, 출입현황판·감시자·환기·가스측정·조명 등 | **작업 당일 시작 전, 사전 작성 금지** |

→ 팀 결정 **D1(당일 체크란은 전날 누락 탐지 대상에서 뺀다)**이 이 표로 뒷받침된다.

### 안전팀의 아웃풋 4가지 (원문 9쪽)

1. **검토·승인 결과:** 신청 내용과 위험 항목을 검토한다.
2. **누락 위험 보완·추가조치 요청:** 빠진 위험에 의견을 달고, 작업 전에 할 조치를 요구한다.
3. **혼재작업 조정:** 필요하면 시간·일정을 조정하고, 함께 할 수 없는 조건을 관리한다.
4. **현장 확인·대면허가 결과:** 해당 작업만이다. 현장 확인, 작업 전 교육, 대면허가 서명이 들어간다.

→ croScan의 출력도 이 4가지에 맞추면 된다: 검토 의견, 추가조치 초안, 혼재 조정안, 대면 확인 항목.

## 3. 허가구분(안전현장허가 / 전산허가)과 2중점검

- **안전현장허가:** 안전대면허가가 **필요하다**. 사례는 「배관 내부 진입 + 아르곤가스 사용」이다.
- **전산허가:** 안전대면허가가 **필요 없다**. 사례는 「(준)밀폐공간 내부 작업」이다.
- 둘을 가르는 기준은 회사가 공개하지 않았다. 조사자는 "아르곤 사용 + 배관 내부 진입이 핵심 원인"이라고 **추정**했다.
- **2중점검**(회의록, 참석자3, 37:58):
  - **Y:** 아침에 현장을 보고 교육한 뒤 작업을 시작한다.
  - **N:** 안전요원이 아침에 다시 와서 교육하지 않는다.
- 사례에서는 Y와 안전현장허가가 같이 나왔고, N과 전산허가가 같이 나왔다. 둘이 원인과 결과인지는 **확인되지 않았다**(Q&A 3번).

## 4. 허가서 종류 5가지와 종류별 체크항목

공통 양식은 우리가 출력물에 맞춰 새로 만든 양식과 같은 구조다. 바뀌는 것은 제목과 「추가정보」 칸의 전용 항목뿐이다.

| 종류 | 영문 제목 | 대조립 비일상작업 |
|---|---|---|
| 밀폐공간 | CONFINED SPACE ENTRY PERMIT | N2 아르곤 사용 조건의 배관 내부 진입 |
| 화기작업 | HOT WORK PERMIT | N1 중대 불량부 절단·가우징·재취부·재용접 |
| 고소작업 | WORK AT HEIGHT PERMIT | N3 블록 상부 임시 인양러그 절단·제거 |
| 중량물인양 | HEAVY LIFTING PERMIT | N4 대조립 블록의 별도 반출·이동 |
| 정전·LOTO | ELECTRICAL ISOLATION / LOTO PERMIT | N5 크레인 제어반 전기계통 고장수리 |

### 종류별 「추가정보」 전용 12항목 (합성 예시 허가서 90~98쪽)

| 화기 | 밀폐 | 고소 | 중량물인양 | 정전·LOTO |
|---|---|---|---|---|
| 화기 종류 | 진입·대피 경로 | 작업 높이 | 대상·계획 중량 | 수리 대상·정격 |
| 절단 대상 | 진입·감시 인원 | 고소 접근수단 | 실중량·무게중심 | 전체 전원 조사 |
| 가연물 방호 | 산소농도 O2 | 발판·안전난간 | 사용 크레인 | 차단 경계·지점 |
| 불티 도달경로 | CO2·CO·H2S | 안전대 형식 | 장비 인양능력 | 잠금·열쇠 관리 |
| 절단부 지지 | 가연성가스 농도 | 안전대 부착설비 | 인양점·러그 상태 | 검전기 작동점검 |
| 절단물 회수 | 급기·배기 배치 | 러그 분리 지지 | 줄걸이 계획 | 무전압 확인 |
| 화재감시자 | 환기팬 독립전원 | 공구 낙하방지 | 반출 이동경로 | 잔류에너지 방전 |
| 용접흄 배기 | 감시·비상연락 | 하부 출입통제 | 안착·받침 조건 | 원격·자동 재기동 |
| 가연성가스 측정 | 구조 준비 | 운반물 접근 배제 | 운전·신호 담당 | 다른 설비 영향 |
| 하부 작업 통제 | 중단 후 재진입 | 고소 화기 방호 | 내부 인원 철수 | 운행 요청 통제 |
| 착수 전 병행중지 | 입·퇴실 대조 | 추락 시 구조 | 구조·통로 인계 | 복구 전 철수 |
| 종료 후 잔불확인 | 동시작업 배제 | 작업 중지 조건 | 크레인 정비 인계 | 격리 해제·인계 |

- 공통 「현장 안전조치」 8항목은 실제 양식과 같다. 공지문·구역통제·전원차단·병행작업·인화성물질·소화장비·통행로·야간조명이다.

| R2 | 블록 외부 대각선 치수검사 | 내부 진입, 블록 등반, 인양 중 측정 | N4 크레인 주행, N1·N3 절단물·불티 |

| R4 | 취부 위치 수동 마킹 | 부재 이동, 가용접, 고소 접근 | N1 지지 해제, N3 상부 분리물, N4 인양물 |
| R5 | 용접 예정 부위 손브러시 청소 | 그라인더, 회전브러시, 가열, 용제 | N1 인접 절단 낙하, N3 러그 낙하, N4 |
| R6 | 소형 부자재 지상 수동 운반 | 크레인·호이스트, 고소, 밀폐 진입 | N3 하부 통과 낙하물, N4 동선, N1 |

### 비일상작업 5종: 허가서 대상

| ID | 작업 | 위험이 커지는 순간 | 확인할 입력(요약) |
|---|---|---|---|
| N1 | 중대 불량부 절단·가우징·재취부·재용접 | **마지막 연결부 절단**. 잔류열·불씨는 작업이 끝난 뒤에도 남는다 | 절단 대상·순서, 지지계통, 분리물 중량·회수, 불티 경로, 가연물 |

| N4 | 대조립 블록 별도 반출·이동 | 시험인양·주행·안착, **고정 확인 전 줄걸이 해제** | 블록·크레인 ID, 중량·무게중심, 경로, 인원 철수 |
| N5 | 크레인 제어반 전기계통 고장수리 | **복구·시험운전**, 다른 팀이 아직 잠금 중인데 복구 | 차단점·잠금 담당, 무전압, 잔류에너지, 복구 권한 |

**참고:** 대형 조립 BAY 1개는 약 43m × 120m(5,160㎡)다. 한화 필리 조선소 사례다.

## 6. 위험쌍을 판정하는 방법 (조사자 원칙)

### 판정 순서 6단계

1. 서로 다른 작업건인지 본다. 한 작업의 준비·후속 단계를 두 작업으로 세지 않는다.
2. 시간이 겹치는지, 또는 앞 작업의 **잔류위험**이 남는지 본다.
3. 두 작업을 잇는 경로를 특정한다. 낙하·이동·불티·가스·공유전원·공통지지 중 무엇인지 본다.
4. 그 경로에 실제 작업자·장비·환기·대피 기능이 노출되는지 본다.
5. 원인 작업과 노출 작업, 중지·순서·장소 분리·상태 확인 조건을 설명한다.
6. 모르는 값은 **「판단 불가 / 확인 필요」**로 남긴다. 겹치지 않는다는 근거도 기록한다.

### 위험 전달방식 7가지

| 전달방식 | 무엇을 보나 | 시간 특징 |
|---|---|---|
| 낙하·전도 | 분리물·받침·무게중심·전도 외곽과 사람 위치 | 마지막 절단, 지지 해제, 안착 후 |
| 이동·충돌 | 블록·후크·줄걸이·크레인 구조물 전체 외곽과 동선 | 주행·회전·시험운전 |
| 화재·불티·잔류열 | 아래·반대편 틈, 가연물, 호스 | **작업 종료 뒤에도 남음** |
| 가스·산소결핍 | 공급원 → 배관·구획 → 호흡 위치 | 시작 전에 측정해도 조건이 바뀜 |
| 공유전원·기계가동 | 같은 설비, 차단점, 연동전원, 복구 권한 | 정지·수리·시험·복구 단계 |
| 공통지지 | 절단 부재가 다른 발판·부재를 받치는가 | 한 팀의 절단이 즉시 영향 |
| 접근·구조 방해 | 문·해치·감시인·덕트·구조 경로 | 실제로 점유될 때만 |

### 쓰면 안 되는 단순 규칙 (원문에 명시)

- "같은 BAY면 위험, 다른 칼럼이면 안전"이라고 보지 않는다. 공장·BAY·칼럼은 **주소**다. 실제 위험영역은 외곽·높이·계통 연결로 본다.
- **종료 시각 = 위험 소멸**로 보지 않는다(잔류열, 잔류가스, 복구·시험).
- 칼럼 번호 28~32가 있다고 기둥 5개를 차지한다고 확정하지 않는다.
- 가상 수치(3.6m, 4.8m, 38톤, 380V)를 실제 값으로 쓰지 않는다. 모르는 값은 null로 두고 담당자에게 물을 질문으로 남긴다.
- AI가 낸 설명·필요조치와 사람의 확인·실제 조치 완료를 **분리**해 기록한다.

## 12. croScan에 주는 의미

1. **입력이 바뀐다.** 허가서 1장이 아니라 **허가서 + 체크리스트 묶음**이고, 허가서 종류가 5가지다.
   - 지금 추출기는 「밀폐」 양식의 추가정보 항목만 안다.
   - 추출기가 **허가서 종류를 판별**하고 **종류별 전용 12항목**을 읽도록 넓혀야 한다.
   - 예시 허가서는 항목마다 설명 문구가 붙은 2단 체크 형식이다.
2. **검토 시간이 정해져 있다.** 전날 15:00에 마감되고, 하루 40~50건이 들어온다.
   - croScan은 마감 뒤에 **그날 들어온 신청 전체를 한꺼번에 대조**하는 구조가 맞다. 혼재 판정에는 다른 반의 신청이 모두 필요하기 때문이다.
3. **출력은 안전팀 아웃풋 4가지에 맞춘다.** 검토 의견, 추가조치 초안(안전요원 수기란), 혼재 조정안, 대면 확인 항목이다.
4. **규칙표와 질문을 바로 만들 수 있다.**
   - 6~8절의 45쌍이 「위험조합 규칙표 [F]」가 된다. 성립 조건, 위험 시점, 조치가 들어 있다.
   - 쌍마다 「필요한 확인정보」가 「확인 질문 템플릿 [H]」가 된다.
   - 상태 값은 판정 결과에 대응한다. C는 조건부 성립(확인 질문), H는 보류, U는 근거 부족, X는 제외다.
5. **시연 데이터:** 9절의 합성 5건이 그대로 "충돌 5쌍 → 조정안" 시연이 된다.
   - 다만 N02 정의가 조사 노트와 다르다(13절). 먼저 하나로 맞춰야 한다.
6. **공정 초점이 바뀌었다.** 이 자료는 **대조립**이 기준이고 **RT는 제외**한다.
   - 기존 문서(이해정리·멘토질문)의 "선행의장 × RT" 시연 설계는 대조립 기준으로 바꿔야 한다. 2026-10-24에 결정한 MVP 공정과 일치한다.

## 13. 자료 안의 불일치와 주의할 점

1. **전산승인을 누가 하는가:** 자료 안에서 설명이 갈린다.
   - 2쪽: "허가신청 및 전산승인은 반장"
   - 6·9쪽: "안전관리자가 전산승인"
   - 실제 허가서 사진: 1쪽은 신청자 = 승인자 = 관리자(MANAGER)다. 2쪽은 신청자가 작업책임자이고 **전산승인자는 관리자(MANAGER) 칸의 사람**이다.
   - 따라서 **전산승인은 작업부서 관리자가 하고, 안전팀은 대면허가를 한다**는 해석도 가능하다. **멘토에게 확인해야 한다.** 승인 주체에 따라 croScan의 사용자(안전팀인지 부서 관리자인지)가 달라진다.
2. **N02 정의가 두 가지다.**
   - 조사 노트(13~59쪽): 「아르곤 사용 조건의 배관 내부 진입」
   - 합성 허가서(88~99쪽): 「폐쇄 블록 내부 유실 부품·이물 회수」. 원문이 "옛 정의"라고 부르는 것이다.
3. **양식 제목 오류로 보인다.** 86~87쪽 양식 제목이 「중량물인양」으로 84쪽과 같다. 71쪽 목록에 따르면 이것은 「정전·LOTO」 양식이어야 한다.
4. **합성 표시:** 예시 허가서에 "합성 작성 예시 | 실제 작업·측정·승인·서명 아님" 문구가 있다. 71쪽에 "윤리문구 제거 작업 필요"라는 메모가 있다. 발표에 쓸 때 합성임을 밝히는 문구를 어떻게 남길지 정해야 한다.
5. **개인정보:** 원본 PDF 2~3쪽 사진에 실명이 있다. 외부 공유 전에 가려야 한다.

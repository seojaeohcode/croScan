## 1. 팀 결정사항 (지금 정할 것)

### D1. D-1 누락 탐지 대상에서 당일 체크란 제외 — 관련: 문제 1
- **상태: 팀원이 확인 중 (2026-10-23 위임).** 아래는 확인 전 임시안이다.
- **권고안:** 허가서의 "현장 안전조치 확인사항" 8칸과 "추가정보" 세부 체크칸은 **D-1 누락 판정에서 뺀다**. 둘 다 당일 작업 시작 전에 적는 칸이고, 사전 작성이 금지돼 있다.
- **D-1에서 AI가 검토할 대상:**
  1. 유해위험요소/추가전달사항 기재가 작업 내용에 비해 빠졌는지 (예: 배관 내부 진입인데 "질식"만 있고 가스·환기 관련 언급이 없음)
  2. 추가정보 분류 선택이 맞는지 (밀폐 / 고소 / 아르곤가스 / 수전구역 / 압력 중 해당 항목이 빠졌는지)
  3. 「작업허가 전 추가조치」 초안 (안전요원이 수기로 쓰는 칸을 AI가 미리 채움)
  4. 병행여부 칸과 혼재 검토 결과가 서로 맞는지
- **당일 체크 대조**(필수 목록 ↔ 실제 체크)는 D-day 확장 기능으로 미룬다.
- 확정: ☐

### D2. 일상/비일상의 뜻 — 관련: 문제 2 (해결)
- **결정:** **일상작업 = 신고서를 올리지 않고 그냥 하는 작업**이다. 위험한지 안전한지와는 관계없다. **비일상작업 = 신고서를 올리는 작업**이고, croScan은 비일상작업 검토에 집중한다.
- 따라서 R03 의장품 용접은 일상작업 그대로 두고, 모순으로 보지 않는다.
- 멘토가 말한 "절대 병행 불가 작업"(TIG 용접 등)은 따로 다루지 않는다. 혼재 규칙 로직을 짜면서 자연스럽게 들어간다.
- 확정: ☑ (2026-10-23)

### D3. 시연 데이터는 팀이 새로 구성 — 관련: 문제 3 (해결)
- **결정:** 기존 그림 속 시간(10~11, 10~12)은 아이디어 설명용 예시일 뿐이다. 시연 데이터는 팀이 새로 짜므로 숫자가 서로 다른 것은 문제가 아니다.
- **재구성할 때 꼭 넣을 경우** (판정 결과가 골고루 나오게):
  1. 시간과 구역이 모두 겹침 → 조정 필요
  2. 끝나는 시각과 시작하는 시각이 딱 맞닿음 (D4 규칙 확인용, 두 가지 모두 넣기)
     - 2-a. 앞 작업이 잔류물을 남김 (예: 도장 → 용접) → 겹침, 조정 필요
     - 2-b. 앞 작업이 남기는 게 없음 (예: 조립 → 취부) → 겹침 아님
  3. 같은 구역이지만 시간이 겹치지 않음 → 단건 결과만
  4. 시간은 겹치지만 구역이 떨어져 있음 → 혼재 없음
  5. 통제구역이 비어 있음 → 확인 필요 (D7)
  6. 일정 변경안을 적용하면 원래 충돌은 없어지지만 다른 작업과 새로 겹침 → 전체 재검토 확인용 (D5)
- **규모:** 하루에 신고가 많이 들어온다는 전제로, 신고·작업 건수를 넉넉히 두고 여러 건의 조정을 시연한다 (D9).
- 참고용으로, 기존 예시 값(N01 RT 10:00~11:00, R01~R03)으로 만들면 1~3번 경우가 나온다:

| 작업쌍 | 시간 관계 | 기대 결과 |
|---|---|---|
| N01 × R02 취부 (09~11) | 10:00~11:00 겹침 | 조정 필요 (RT 통제구역 안) |
| N01 × R01 조립 (08~10) | 10:00에서 맞닿음 | D4 규칙에 따름 (주의) |
| N01 × R03 용접 (13~15) | 겹침 없음 | 단건 결과만 |

- 변경안 예시는 **RT를 11:00~12:00으로 옮기는 안**을 쓴다. 이 경우 R02와 맞닿기만 하고 R03과는 겹치지 않는다. 어느 쪽을 옮길지는 멘토 질문 M4의 답에 따라 바꾼다.
- 확정: ☑ (2026-10-23)

### D4. 맞닿은 작업의 겹침은 앞 작업의 잔류 위험으로 판정 — 관련: 문제 4
- **결정 (팀 의견, 2026-10-23):** 앞 작업이 10:00에 끝나고 뒤 작업이 10:00에 시작하는 경우, 겹치는지는 **작업마다 다르다**.
  - 앞 작업이 **잔류물(가스·증기 등)을 남기면** 바로 시작해도 **겹침**으로 본다. 예: 도장 뒤 바로 용접
  - 남기는 게 없으면 바로 시작해도 **겹침 아님**이다. 예: 조립 뒤 바로 취부
- **판정 방법:** 앞 작업의 시간을 `종료 시각`까지가 아니라 **`잔류 위험이 해제될 때`**까지로 늘려서 비교한다.
- **작업 종류별로 필요한 정보 (잔류위험 기준표):**

| 필드 | 뜻 | 예시 (합성) |
|---|---|---|
| `잔류위험` | 끝난 뒤 남는 것 | 인화성 증기 / 유해가스 / 없음 / 미확인 |
| `해제방식` | 언제 풀리나 | 시간(N분 경과) / 측정(가스측정 통과) / 즉시 |
| `해제시간` | 시간 방식일 때 걸리는 시간 | 30분 (근거 없으면 비워 둠) |
| `영향받는 뒤 작업` | 어떤 작업이 이어지면 위험한가 | 화기작업(용접·절단) / 밀폐공간 진입 / 전체 |

- **해제 방식이 "측정"이면** 시간을 계산하지 않는다. 대신 "가스측정 통과 후 착수"를 체크리스트 항목으로 넣는다.
- **잔류위험이 `미확인`이면** 겹침 여부를 정하지 않는다. 결과는 **`확인 필요`**로 안전팀에 넘긴다.
- 잔류 위험은 **방향이 있다**. "도장 → 용접"은 위험하지만 "용접 → 도장"은 다를 수 있으므로, 앞 작업과 뒤 작업을 구분해서 본다.
- 일반 규칙: 판정은 일별 구간 단위로 하고, 여러 날 신고는 날짜별로 나누며, 야간 작업은 자정을 넘는 구간을 처리한다.
- 시연에서는 몇 가지 작업 종류만 합성 값으로 채우고 "합성"이라고 표시한다. 실제 값은 멘토 질문 M2로 확인한다.
- 확정: ☑ 방향 (2026-10-23) · ☐ 작업별 값

### D5. "후속 조율 기능"의 정의 — 관련: 문제 5
- **상태: 다른 팀원이 화면을 작성 중 (2026-10-23).** 아래는 참고용 제안이다.
- **권고안:** 일정 변경안을 고르면 다음 두 가지를 한다.
  1. **관련 작업 전체 재검토:** 원래 문제였던 쌍만이 아니라 같은 날·인접 구역의 모든 작업을 다시 비교한다.
  2. **영향 작업 목록 생성:** 옮긴 작업 때문에 영향을 받는 다른 협력업체 작업과 후속 공정(예: 배관 설치 후 누설 검사)을 나열하고, 담당 반장에게 확인을 요청하는 목록을 만든다.
- **MVP 범위:** 1번은 구현한다. 2번은 화면에 목록으로만 보여 주고, 실제 알림 발송은 하지 않는다.
- 최신 MVP 3번 이미지의 "?" 패널을 이 정의로 교체한다.
- 확정: ☐

### D6. 선행의장 작업장 공간 모델은 합성으로 만든다 — 관련: 문제 6
- **상태: 도면 자료를 팀원에게 확인 중.** 결과를 받으면 이 항목을 다시 정한다. 아래는 확인 전 임시안이다.
- **권고안:** 실제 도면이 없으므로 **합성 작업장 구역표**를 만들고 "합성"이라고 표시한다.
  - 위치 표기는 실제 허가서 형식을 따른다: `공장 – BAY – 칼럼(구역)` (허가서 예: "대조립21공장 2BAY 2B-32 칼럼")
  - 구역 관계표: `구역A, 구역B, 관계(동일/인접/상하/통로연결), 근거=합성`
  - 블록 위 고소 작업과 블록 아래 작업은 상하 관계로 표현한다.
- GOLAR 선박 3D는 **발표 시각화 보조로만** 쓴다. 공장 선행의장 판정 근거로 쓰지 않는다.
- 확정: ☐

### D7. RT 통제범위는 조사해서 채운다 — 관련: 문제 7
- **상태: 아직 안 한 작업 (5절 W1).** RT 통제범위처럼 판정에 필요한데 없는 정보는 찾아서 채워야 한다. 작업·공정별로 어떤 정보가 필요한지 설계하는 일을 아직 하지 않았다.
- **조사 전까지의 임시 방식:** 신고서에 `통제구역(구역 ID 목록)`과 `통제시간` 필드를 두고, 입력된 값을 판정에 쓴다.
- 통제구역이 비어 있으면 혼재 결과는 **`확인 필요`**가 되고, 안전팀에 질문으로 넘어간다.
- 시연 데이터의 N01 통제구역은 Z-1 전체로 둔다. 「합성 작업계획서」 이미지의 "통제구역이 A구역을 포함" 설정과 같다.
- 확정: ☐

### D8. 7공정 확정 — 관련: 문제 8 (해결)
- **결정:** 7공정은 **판넬조립 · 대조립 · 선행의장 · 선행도장 · PE장 · 탑재 · 선체도장**이다. 빠져 있던 7번째는 선체도장이다.
- 내업/외업 구분:
  - 내업: 판넬조립 · 대조립 · 선행의장 · 선행도장
  - 외업: 탑재 · 선체도장
  - **PE장: 내업과 외업 둘 다 해당** (팀 확인, 2026-10-23). 교안 흐름도에는 외업 부문에만 그려져 있으니 발표 자료에서 주의한다.
- 발표에서는 교안의 공정별 실사진으로 7공정을 설명할 수 있다.
- 확정: ☑ (2026-10-23)

### D9. 멘토 수치는 "어떤 논리로 보여 줄지"의 방향으로 쓴다 — 관련: 문제 9
- **해석 (팀 의견, 2026-10-23):** 멘토가 말한 수치는 정확한 통계라기보다, **무엇을 근거로 설득하라는 방향 제시**다.
  - **"하루 40~50건"** → 시연은 **하루에 신고가 많이 들어온다는 전제**로 구성한다. 신고·작업 건수를 넉넉히 두고, 여러 건을 조정하는 장면을 보여 준다. (D3 시연 규모와 연결)
  - **"승인 대기 30분~1시간" 같은 시간 수치** → 이 사업이 **얼마나 돈이 되는지 추산할 때** 참고하라는 뜻이다. 예: 절감 시간 × 건수 × 인건비
- **사용 원칙:**
  - 실제 수치는 따로 조사한다 (5절 W2). 조사 전까지는 발표에서 "현업자 인터뷰 발언"이라고 출처를 밝힌다.
  - 사고 감소율은 근거 없이 주장하지 않는다.
- 확정: ☑ 방향 (2026-10-23) · ☐ 실제 수치

## 2. 멘토 확인 질문

### 높음 — 답에 따라 기능 로직이 바뀜

**M1. 신고서 작성 시점과 안전팀이 추가하는 내용** — 관련: D1
- 전산으로 신청할 때(작업 전날) 반장이 실제로 채우는 칸은 어디까지인가요? 유해위험요소와 추가정보 분류(밀폐·고소·압력 등)도 이때 작성하나요?
- 안전팀이 검토하면서 가장 자주 추가하거나 고치는 내용은 무엇인가요? (예: 받은 허가서 사진의 수기 추가조치 "가스농도 측정·환기·감시자 배치")
- `2중점검 대상 Y/N`은 어떤 기준으로 정해지나요?
- → **답에 따라 바뀌는 것:** AI가 누락을 찾을 대상 칸과 추가조치 초안의 내용

**M2. 끝난 뒤에도 위험이 남는 작업** — 관련: D4
- 작업이 끝난 뒤에도 가스·증기 같은 위험이 남아서, 바로 다른 작업을 하면 안 되는 작업은 어떤 것들이 있나요? (예: 도장, 가스를 쓰는 작업, 압력 테스트 등)
- 그런 경우 다음 작업은 언제부터 시작하나요? 정해진 대기 시간이 있나요, 아니면 가스측정 등으로 확인한 뒤 시작하나요?
- → **답에 따라 바뀌는 것:** 잔류위험 기준표의 작업 목록과 해제 방식

**M3. RT 검사의 통제구역과 시간대** — 관련: D4, D7
- 선행의장에서 RT를 할 때 통제구역은 어떻게 정하나요? (반경 / 구역 단위, 정하는 사람)
- RT는 보통 언제 하나요? 다른 작업이 적은 시간(야간·휴게시간 등)에 몰아서 하는지, 일과 중에도 하는지 궁금합니다.
- RT 전후의 준비·철수 시간도 통제 시간에 포함되나요?
- → **답에 따라 바뀌는 것:** 시연 시나리오의 현실성, 경계 인접 판정, 통제시간 필드

**M4. 충돌이 났을 때 어느 작업을 옮기는가** — 관련: D3, D5
- 검사(비일상)와 생산(일상)이 충돌하면 보통 어느 쪽 일정을 바꾸나요? 그 결정은 누가 하나요? (안전팀 / 생산 / 협력사 협의)
- 일정을 바꿀 때 다른 협력업체와 후속 공정에는 어떻게 알리고 확인하나요?
- → **답에 따라 바뀌는 것:** 변경안을 추천하는 방향, 후속 조율 기능의 대상

**M5. 선행의장 작업장의 위치 단위** — 관련: D6
- 현장에서는 선행의장 작업 위치를 어떤 단위로 부르나요? (공장·BAY·칼럼·블록번호 등)
- "인접해서 위험하다"는 판단은 어떤 기준으로 하나요? (같은 BAY, 같은 블록, 위아래 등)
- 저희가 선행의장 작업장 구역을 단순한 그림으로 그려 시연해도 현실과 크게 어긋나지 않을까요?
- → **답에 따라 바뀌는 것:** 합성 공간 모델의 단위와 인접·상하 관계 정의

### 중간 — 답에 따라 발표 자료가 바뀜

**M7. 수치 인용과 근거** — 관련: D9
- 말씀해 주신 하루 40~50건, 승인 대기 30분~1시간을 발표에서 "현업자 인터뷰 발언"으로 인용해도 될까요?
- 실제 신고 건수나 검토 시간을 대략이라도 확인할 수 있는 방법이 있을까요?

## 3. 멘토에게 보낼 요약본 (바로 복사해 보내는 용도)

> 멘토님, 지난 멘토링 내용을 반영해 croScan을 **"위험작업신고서 단건 누락 검토 + 혼재 위험 검토 → 안전팀 승인 전 검토 자료 생성"**으로 정리했습니다. 시연은 **선행의장(의장품 조립·취부·용접) × 배관 용접부 RT 검사**로 준비하고 있습니다. 개발 전에 몇 가지 확인 부탁드립니다.
>
> 1. 전산 신청 시점에 반장이 채우는 칸은 어디까지인가요? 안전팀이 검토하며 가장 자주 추가하는 내용은 무엇인가요?
> 2. RT 검사의 통제구역은 어떻게 정하고, 보통 어느 시간대에 하나요? 준비·철수 시간도 통제에 포함되나요?
> 3. 검사와 생산 작업이 충돌하면 보통 어느 쪽을 옮기고, 누가 결정하나요?
> 4. 선행의장 작업 위치는 현장에서 어떤 단위(공장·BAY·칼럼·블록)로 부르나요? 인접 위험은 어떤 기준으로 판단하나요?
> 5. 2중점검 대상 Y/N은 어떤 기준으로 정해지나요?
> 6. 하루 40~50건, 대기 30분~1시간 수치를 발표에서 "현업자 인터뷰 발언"으로 인용해도 될까요?
> 7. 비식별 처리한 신고서와 안전팀 코멘트 예시를 몇 건 받을 수 있을까요?
> 8. 끝난 뒤에도 가스·증기 같은 위험이 남아 바로 다른 작업을 하면 안 되는 작업은 어떤 것들인가요? 그 경우 다음 작업은 정해진 대기 시간 뒤에 시작하나요, 가스측정으로 확인한 뒤 시작하나요?
>
> 정리한 자료도 함께 보내드리니 검토 부탁드립니다. 감사합니다.

## 5. 아직 안 한 작업

### 조사·설계 (나중에 Claude에게 조사·정리를 맡길 예정)

**W1. 작업·공정별 필요 정보 설계 — 아직 안 함**
- 7공정과 각 공정의 작업 종류마다, AI가 판정하려면 **어떤 정보가 필요한지 항목을 설계**하고, 없는 값은 **조사해서 채운다**.
- 이미 필요하다고 드러난 정보:
  - RT 검사: 방사선 통제범위, 통제시간, 준비·철수 시간 (D7)
  - 작업별 잔류위험: 남는 것, 해제 방식, 해제 시간, 영향받는 뒤 작업 (D4)
- 이 밖의 작업(도장, 용접, 밀폐공간 작업, 압력 테스트 등)도 같은 방식으로 정리한다.

**W2. 수치 조사 — 아직 안 함** (D9)
- 하루 신고 건수, 건당 검토 시간, 승인 대기 시간에 대한 공개 자료를 조사한다.
- 사업성 추산(절감 시간 × 건수 × 인건비)에 쓴다.

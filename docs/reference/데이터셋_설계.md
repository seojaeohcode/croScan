## 1. 로직과 데이터의 연결

```
① 같은 호선·BAY·날짜           ← [A] 위험작업신고서  [B] 작업계획서  [C] 작업장 배치
② 같은 블록 / 가까운 칼럼       ← [D] 블록 배치표  (+ A 작업내용 글에서 블록번호 추출)
③ 블록별 시간이 실제로 겹침      ← [B] 작업계획서 (블록 × 시간 행)  [E] 작업종류 사전(잔류위험)
④ 위험조합 규칙에 해당          ← [F] 위험조합 규칙표
   정보가 모자라면 질문 생성     ← [H] 확인 질문 템플릿
(별도) 신고서 단건 누락 검토     ← [G] 작업별 체크 기준
(검증) 결과가 맞았는지          ← [I] 정답 평가셋
```

**연결 키** (모든 데이터셋에서 같은 형식으로 써야 한다)
- `호선` — 예: 3595
- `공장`·`BAY`·`칼럼` — 예: 대조립21공장 · 2BAY · 2B-32
- `블록ID` = 호선 + 블록번호 — 예: 3595-E18. 배가 다르면 블록번호가 같아도 다른 블록이다.
- `날짜`, `작업ID`, `신고ID`

### [B] 작업계획서 — 블록 × 시간 단위 (깔때기 ③의 핵심)
신고서 1건이 "9개 블록 × 4일"이면, 작업계획서는 그것을 **블록별·시간별 행으로 풀어 쓴** 것이다.

| 필드 | 예시 |
|---|---|
| 작업ID | W-0412 |
| 연결 신고ID | BS22-IV-20261014-1305 (일상작업이면 비움) |
| 일상/비일상 | 비일상 |
| 수행업체 / 담당팀 | (주)혁신이엔지 |
| 작업종류 | 밀폐공간 내부 작업 |
| 블록ID | 3595-E18 |
| 블록 내 위치 | 탱크 내부 / 상부 / 하부 / 미확인 |
| 날짜 · 시작 · 종료 | 2026-10-14 · 13:00 · 15:00 |
| 인원 · 장비 · 사용물질 | 2명 · 환기팬 · — |
| 선행작업 / 변경 가능 범위 | 같은 날 오후 안에서 이동 가능 |

- 현대힘스 양식의 칸(작업위치·대상ID·시작일시·종료일시·작업장비·사용물질·선행작업·혼재작업)과 같은 내용이다.

### [I] 정답 평가셋
- 합성 데이터의 작업쌍마다 **기대 결과**를 사람이 미리 적는다: 깔때기 몇 단계에서 걸러졌는지, 최종 판정, 이유.
- 꼭 포함할 경우는 팀 결정 문서 D3의 6가지 경우와 같다 (겹침, 맞닿음 2종, 구역 다름, 정보 부족, 변경 후 새 충돌).
- 정답은 AI 입력과 분리해서 보관한다.

## 4. 시연용 합성 규모 (제안)

깔때기가 숫자로 줄어드는 게 보이도록, D9 방향(하루 신고가 많다는 전제)에 맞춰 넉넉히 만든다.

| 항목 | 규모 |
|---|---|
| 호선 | 1척 (+ 블록번호가 같은 다른 호선 1척, 오탐 확인용) |
| 공장 · BAY | 1공장 2BAY |
| 칼럼 | BAY당 20개 정도 |
| 블록 | 15~20개 |
| 날짜 | 1~2일 |
| 신고서 (비일상) | 10~15건 |
| 작업계획서 행 (일상 + 비일상 풀어 쓴 것) | 40~60행 |
| 기대 깔때기 | 후보 40 → 가까움 8 → 시간 겹침 3 → 조정 필요 1 (예시) |

## 5. 만드는 순서

1. **[C] 작업장 배치** — 팀원 도면 확인 결과를 반영한다.
2. **[D] 블록 배치표** — 어느 날 어느 블록이 어디 있는지 정한다.
3. **[E] 작업종류 사전**, **[F] 위험조합 규칙표** — 시연에 쓸 작업 종류만 정한다 (6~8종).
4. **[B] 작업계획서** — 블록·시간 행을 만든다. 깔때기 경우가 골고루 나오게 배치한다.
5. **[A] 위험작업신고서** — B의 비일상 행을 묶어서 실제 양식처럼 "여러 블록 × 여러 날 × 하루 종일"로 쓴다. 일부는 블록번호를 빼서 정보 부족 경우를 만든다.
6. **[G] 체크 기준**, **[H] 질문 템플릿**
7. **[I] 정답 평가셋**

C·D가 먼저인 이유: 위치와 블록이 정해져야 작업과 신고서를 그 위에 올릴 수 있다.

## 6. 아직 모르는 것

- 칼럼 번호가 가까우면 실제로도 가까운가 (멘토 M5)
- 블록별 작업 시간이 실제로 어느 문서에 있나: 작업계획서인지, 생산 일정인지 (멘토 M5)
- 신고서의 칼럼 1개와 블록 9개의 관계: 9개 블록이 그 칼럼에 다 있는지, 칼럼은 대표 위치인지
- 작업종류별 영향 범위·잔류위험 실제 값 (팀 결정 문서 5절 W1)
- 작업장 도면 (팀원 확인 중)

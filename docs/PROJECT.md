# croScan — 프로젝트와 기여

## 출발점

- 조선소의 허가서는 개별 작업을 설명합니다. 위험은 작업들이 같은 시간·공간·장비를 공유할 때도 생깁니다.
- croScan은 서류에서 빠진 조건을 보완하고, 함께 진행되는 작업의 위험을 검토하도록 만든 사전검토 도구입니다.
- 결과물: 작업반장 화면, 안전관리자 화면, 문서 생성, QA 의견 수집·처리 시스템, 시연 영상 시스템.

## 서재오의 기여

- **전체 개발** — 프론트엔드·백엔드·PDF 처리·AI 연동·규칙 판정·상태 관리·평가 도구 구현.
- **팀 QA 시스템** — 화면 상태·파일 첨부를 포함한 피드백 접수, 처리 결과·메모·진행 상태 공유.
- **영상 시스템** — 시연·영상 제작 시스템 구현. [제작 소스](../media/README.md)와 [최종 영상](presentation/README.md) 공개.
- 팀 프로젝트의 현장 의견·검토와 개인 구현 책임을 구분합니다. 전체 개발 범위는 본인의 확인을 기준으로 기록했습니다.

## 가장 큰 변경: 자동 일정 조정을 지웠습니다

1. 초기에는 위험한 작업을 찾아 일정을 자동 조정하는 방향을 검토했습니다.
2. 현장 의견에서 실제 일정 협의는 작업반장들이 하고, 안전관리자는 조정 권고를 전달한다는 점을 확인했습니다.
3. 자동 일정 변경을 제거하고, **누구에게 무엇을 확인할지·어떤 근거로 협의할지**를 담은 문안과 게시 서류로 바꿨습니다.

기능 수보다 업무의 권한과 책임에 맞는 흐름을 우선했습니다. [설계 변경 이력](19_설계결정과_변경이력.md)

## 결과와 범위

- **2026 K-조선해커톤 대한조선학회장상** — 수상 정보는 본인 제공.
- 합성 허가서·작업계획서로 전체 흐름을 시연하고 규칙·API·상태 관리를 검증했습니다.
- 실제 조선소 운영 시스템과의 연동, 현장 배포, 사용자 시간 절감의 실측은 완료 실적으로 주장하지 않습니다.
- 발표 자료의 연간 절감액은 가정에 따른 추정입니다. 실측 성과와 구분합니다.

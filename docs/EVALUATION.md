# 평가 결과와 재현

**실행 확인: 2026-11-12.** 합성 자료의 결과와 현장 성능을 구분합니다. 아래 규칙·검색 평가는 실제 코드로 재실행했습니다. LLM 모델의 과거 실험은 별도로 표시합니다.

## 1. 위험쌍 탐지 — 현재 코드 재실행

입력은 **합성 허가서 10건 + 작업계획서 40건**입니다. 비일상×비일상 45쌍, 일상×비일상 400쌍을 평가합니다. 일상×일상은 이번 평가 범위 밖입니다.

| 확인 항목 | 결과 | 해석 |
|---|---:|---|
| 범위 안 정답 위험쌍 탐지 | **10 / 10** | 정답표에 지정한 위험쌍의 누락 없음 |
| 정답 우선순위 일치 | **8 / 10** | 나머지 2쌍은 더 높은 위험 순위로 판정 |
| 근접 사례의 확정 오경보 | **0 / 5** | 이 중 3쌍은 거리·잔류위험 확인이 필요해 보류 |
| 정답표 밖 경보 | **13쌍** | 별도 검토가 필요하며, 오경보가 없다는 의미가 아님 |
| 전체 출력 | **26쌍** | 정답 10 + 근접 보류 3 + 정답표 밖 13 |

- 정답표 `skeleton.json`은 **채점 도구만 읽습니다**. 탐지 규칙은 정답표를 입력으로 받지 않습니다.
- 개발자가 만든 소규모 합성 자료입니다. 독립 검증셋의 재현율·정밀도나 실제 조선소 정확도로 일반화할 수 없습니다.
- 2쌍의 우선순위 차이와 13쌍의 추가 경보는 후속 검토 대상으로 남깁니다.

```bash
python tools/check_pairs.py
python tools/check_pairs.py -v
```

## 2. 근거 검색 — 현재 코드 재실행

개발자가 작성한 **20개 질의**에 대해, 예상 근거가 상위 결과에 포함되는지 확인합니다.

| 기준 | 상위 3개 | 상위 6개 | 상위 12개 |
|---|---:|---:|---:|
| 예상 근거 중 하나 이상 포함 | 16 / 20 | 20 / 20 | 20 / 20 |
| 예상 근거를 모두 포함 | 15 / 20 | 19 / 20 | 20 / 20 |

- 일부 질의에는 기대하는 근거가 여러 개입니다. ‘하나 이상’과 ‘모두’의 분모는 같지만 판정 조건이 다릅니다.
- 검색 결과에 근거가 들어 있다는 시험입니다. 생성 답변의 정확도·인용 충실도·현장 질의 전반의 성능을 측정한 수치가 아닙니다.

```bash
python tools/eval_retrieval.py
```

[실행 로그](validation/2026-11-12/eval_retrieval.py.txt) · [질의와 채점 코드](../tools/eval_retrieval.py)

## 3. 자연어 해석 — 과거 실험 기록

- 2026-10-31 기록에서, 기대 정보 **1,000개** 중 규칙만 사용했을 때 285개, 규칙+AI+의미 검사를 사용했을 때 794개를 올바르게 해석했습니다.
- 입력 문장은 **기본 시나리오 30개 × 값 변형 5개 × 표현 8개 = 합성 문장 1,200개**입니다. 실제 작업자 1,200명의 발화가 아닙니다.
- 원본 실행 JSONL이 이 저장소에 없고 이후 코드가 바뀌었습니다. 이번 정리에서는 해당 모델 실험을 재실행하지 않았습니다.
- 발표의 285→794는 이 과거 기록을 인용합니다. 현재 버전의 검증 성능으로 대체해서 읽지 않습니다.

## 4. 회귀 시험과 실행 조건

```bash
python tools/check_release.py
python tools/check_release.py --pdf
```

- API 접근 통제, QA 상태, 중복 제출, 답변 버전 충돌, AI 제안 검사, 규칙, 검색, PDF 출력 등을 기존 시험 도구로 검사합니다.
- AI 응답을 가짜 응답으로 대체하는 단위 시험은 **실제 모델 추론 시험과 구분**합니다.
- 저장된 제출본을 검증하는 `check_submissions.py`, `check_submit_link.py`는 `CROSCAN_KEEP_SUBMISSIONS=1`로 실행합니다.
- 프록시 설정 검사: `python tools/check_proxy_headers.py --conf deploy/oidc-proxy/nginx.conf`.
- 자세한 실행 결과·환경·재시험 기록은 [검증 기록](validation/2026-11-12/README.md)에 남깁니다.

## 5. 아직 검증하지 않은 것

- 현장 운영 중의 누락·오경보율, 사고 감소, 사용자 작업시간 절감.
- 실제 사내 SSO·결재 시스템·운영 데이터 연동.
- 실제 LLM 서버를 연결한 이번 버전의 전체 추론 성능과 부하.
- 발표의 연간 비용 절감액은 입력 가정에 따른 추정치입니다. 실제 절감 실적으로 주장하지 않습니다.

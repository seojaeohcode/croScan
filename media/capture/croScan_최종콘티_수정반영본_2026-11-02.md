## 1. 시연의 중심 이야기

**반장이 보충하고 확인한 작업 정보가 안전관리자의 여러 작업 검토로 이어지고, 부족한 정보는 다시 확인한다. 이어 협조 문자를 작성·전달하고, 반장 간 일정 조율과 기존 절차의 승인을 마친 상황에서 현장 전달 자료를 준비한다.**

주 사례는 0731 화기 작업과 WP-01 E42P 도장 작업이다. 서류 입력 → 정보 보완·사람 확인 → 체크리스트 → 제출 → 작업 간 위험 검토 → 필요한 추가 확인 → 조율 요청 → 외부 협의·승인 → 현장 전달 자료 순서로 진행한다.

## 2. 사례와 촬영·편집의 연결

- 주 사례: 0731 화기 작업 × WP-01 E42P 도장 작업. 시연용 자료를 사용한다.
- 원본 신청시간 08:00~16:59와 반장이 확인한 실제 작업시간 13:00~15:00을 구분한다.
- 반장 확인 위치: 3BAY 08~10칼럼 E42P 블록 상부.
- 도장 작업: 13:30~15:00. 주 사례의 겹침: 90분.
- 원래 신청시간도 도장 작업시간을 포함한다. 90분 겹침 자체를 반장 답변 때문에 새로 생긴 결과로 설명하지 않는다. 실제 시간·위치와 그 출처가 구체화되어 다른 작업 검토에 쓰이는 것을 보여준다.
- V01~V11은 작업반장 화면, V12부터는 안전관리자 화면이다. V14B에서는 추가 확인의 순환을 보여주기 위해 잠깐 반장 화면으로 돌아간다.
- V04는 V03의 장문 처리에 이어 “그런데 오타가 섞이면?”을 확인하는 본편 장면이다. 같은 질문·같은 시작 상태에서 같은 사실을 비교하고, V05는 V04 결과를 이어서 확인·반영한다.
- V14B는 실제 남아 있는 확인사항으로 촬영한다. 주 사례에 적합한 미확인이 없으면 실제 미확인이 있는 작업을 ‘추가 확인 예시’로 표시하고, 종료 후 0731 주 사례로 돌아온다.
- V15는 별도 작업쌍의 선택적 추가 검토다. 본편에서 사용할 경우 별도 예시임을 표시하고, V16에서 0731 주 사례로 복귀한다. 생략하면 V14B → V16으로 연결한다.
- V17B의 일정 조율과 생산부서 전산승인은 앱 밖에서 완료된 시나리오 가정이다. 이후 V18~V19는 그 협의·승인을 마친 상황에서 현장 전달 자료를 작성하는 장면이다.
- 협조 문자는 앱에서 복사하고 기존 연락 수단으로 전달한다. 외부 협의·승인을 앱의 자동 처리나 별도 승인 버튼으로 연출하지 않는다.
- 자료를 열어 근거·사례를 확인하는 장면은 해당 업무 중 필요한 부분을 펼쳐 보는 과정이다. 모든 사용자가 모든 자료를 반드시 열어야 하는 단계로 표현하지 않는다.
- 반복 확인은 축약하되, 계획서·체크리스트의 필요한 확인과 제출 완료 상태는 실제 화면으로 이어진다.
- 21클립은 PPT 삽입 단위다. 최종 길이·타임코드는 촬영·편집 후 정한다.

AI 제안은 실제 결과와 근거를 보여주고 사람이 확인·선택한다. 기본 규칙 결과·고정 문안을 AI 성공 결과로 대신 사용하지 않는다. 모델이 문안 재료를 고르는 것과 사람이 협의·승인하는 것을 구분한다.

### V17B · 문자 전달 후 일정 조율·기존 승인 완료를 연결

**보는 사람:** 시나리오 연결 설명 → 안전관리자

**관객의 의문:** 협조 문자로 요청한 뒤, 어떤 상황에서 현장 전달 자료를 작성하나?

**장면의 전제**

협조 문자를 기존 연락 수단으로 전달하고, 그 내용을 토대로 작업반장들이 일정·순서를 조율한 뒤 생산부서 승인권한자의 전산승인까지 마친 상황을 가정한다. V18~V19의 현장 전달 자료는 이 다음 단계다.

**화면 순서**

1. V17의 협조 문자 복사 결과에서 전환한다.
2. 짧은 연결 화면에 `문자 전달 → 반장 간 일정 조율 → 생산부서 전산승인`을 순서대로 표시한다. `앱 외부 진행 · 협의·승인 완료를 가정`을 함께 표시한다.
3. 이 단계는 앱 조작 성공 화면 대신 시나리오 전환으로 표현한다. 합성 승인 화면·실제 승인자 서명을 만들지 않는다.
4. `협의·승인 후 현장 전달 자료 준비`로 V18에 연결한다.
5. V18~V19에 구체적인 변경 시간·조치가 들어간다면 협의 후로 설정한 자료와 일치하는지 확인한다. 변경 시간을 제시하지 않는 구성에서는 조정 완료 전후의 겹침 감소를 보여주지 않는다.

**자막 · 표시 순서**

| 번호 | 표시할 화면·시점 | 최종 주자막 | 보조자막 |

| 49 | 문자 전달에서 반장 간 협의로 연결되는 전환 화면 | 전달한 협조 문자를 바탕으로 작업반장들이 일정을 조율합니다. | 앱 외부 진행 · 시나리오 가정 |

## 6. 제작 인계 메모

- 한 순간에 핵심 자막 한 문장과 강조 지점 하나만 둔다. 설명할 UI와 원문을 가리지 않는다.
- 실행 예고는 행동 전에, 결과 설명은 실제 결과가 보인 뒤 표시한다.
- 각 클립은 마지막 결과를 읽을 수 있는 화면에서 끝낸다.
- AI 제안·자유 질문·관련 자료·사례의 실제 결과와 출처를 추가 촬영한다. 23번의 ‘실제 사례’는 출처에서 실제 사례임을 확인할 수 있는 자료로 촬영한다.
- V17B의 외부 협의·전산승인 완료 가정 이후에 V18~V19를 배치한다. 발행본은 그 상황의 실제 채택 내용과 같은 작업·같은 판으로 연결한다. 자료 발행이 기존 승인을 대신하는 것으로 표현하지 않는다.
- 최종 영상과 자막 타임코드는 아직 제작 전이다. 이 문서는 콘티·문구 전달본이다.
- 기능 대조 기준은 17a202b 커밋과 기존 기능 대조표다. 기존 manifest는 수정 전 19클립·51자막 번호를 사용한다. 이번 번호와 혼용하지 않으며, 아래 이전 번호 대응표로 연결한다.

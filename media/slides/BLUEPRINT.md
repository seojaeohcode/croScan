# croScan 본선 발표 구성안 — 설계도 (구성자 작성, 모든 제작 에이전트 공통 기준)

> **[변경, 사용자 지시] 최종 산출물은 PPTX다.**
> - **변환 방식:** 각 장표는 고해상도 이미지로 넣고, `.vid[data-v]` 상자 자리에는 실제 시연 mp4를 재생되게 얹는다. `<aside class="notes">`는 발표자 노트로 옮긴다(`export_slides.mjs` → `make_pptx.py`). PDF는 함께 낸다.
> - **시연 영상:** 기능(functional/valuable) 장표에는 시연 모션그래픽 영상을 넣고, `.vcap`으로 「영상 몇 초에 무엇」을 설명한다.
> - **발표자 노트:** 모든 장표에 넣는다. 설명 3~6문장, 근거, 필요 자료를 담는다.

## 1. 공통 규칙 (어기면 결함)
1. **CSS는 `parts/deck.css`만 쓴다.** 새 클래스가 필요하면 자기 파일 맨 위 `<style>`에 `.p3-...`처럼 파트 접두어를 붙여 넣는다. deck.css는 디자인 담당만 고친다.
2. **장표는 `<section class="slide">`, 부록은 `<section class="slide apx">`로 쓴다.** 각 장표 안에 `{{FT}}`를 정확히 하나 넣는다. 발표 시간대가 있으면 `{{FT:3:30–3:55}}` 형식으로 쓴다.
   - 머리는 `.hd`(h1, `.sp`, 칩, 뱃지)로 만든다.
   - 핵심 메시지는 `.key`, 본문 영역은 `.body`(top 285, bottom 96)에 둔다.
   - 근거는 `.note`(bottom 78)에, 필요 자료는 `.need`에 쓴다.
   - `.body` 안 배치는 absolute 또는 flex 중 편한 것을 쓴다.
3. **글자 크기 하한:** 본문 21px 이상, 근거 줄 17px 이상. 한 장에 주장은 하나만 둔다. 글이 넘치면 줄이거나 부록으로 옮긴다. **글자가 상자 밖으로 넘치거나 겹치면 결함이다.**
4. **그림:** 아이콘·도식은 인라인 SVG로 직접 그린다. 팔레트는 남색 #1B365D, 진남색 #14284A, 초록 #1E6B47, 청록 #1F9A8E, 주황 #D4561F, 금색 #E2A72E, 연회색 #E6EBF1, 배경 #F2F5F9다. 선은 둥근 끝 3~4px로 한다. 이모지와 클립아트는 금지한다.
   - 준비된 것: `svg/*.svg`(Codex가 그린 일러스트로 생기는 중이며 `svg/INDEX.md` 참고), `img/*.png`(생성 사진: cover, part1~5, round_block, round_weld).
   - 실제 앱 화면: `..\croScan_demo_videos\final19\*_대표화면.png`(21장)와 `..\croScan_demo_videos\work19\sheets\V*_sheet.png`(프레임 모음, 잘라 쓰려면 PIL 대신 CSS `object-position`을 쓴다).
   - 로고: `..\croScan_video\public\croscan_logo_real.png`.
   - 이미지 경로는 deck.html 기준 상대경로(`img/..`, `svg/..`, `../croScan_demo_videos/...`)로 쓴다.
5. **사실 규칙(사용자 지시):**
   - 숫자는 원문 그대로 쓰고 출처를 note에 단다.
   - 출처는 정부·공공기관(고용노동부·KOSHA 등), 조선 3사 공식보고서, 조선해양플랜트협회·대한조선학회·국책연구기관, 팀의 현장 인터뷰·멘토링 기록만 쓴다. 해외 자료와 잡다한 논문은 쓰지 않는다.
   - 멘토·인터뷰 수치(신규 허가 약 8건/일, 작성 15분, 안전 검토 5분, 계획서 검토 10분, 한 팀 40~50건, 대기 30~60분, 내업:외업 60:40)는 **「멘토·현장 참고값(실측 아님)」**으로 표시하고 합산하지 않는다.
   - 효과는 「가정 시나리오」로 쓴다. 사고 감소율은 약속하지 않는다.
   - **금지 표현:** 「HiSEs보다 우수」, 「업계 최초」, 「기존 시스템엔 없다」, 「AI가 승인」, 「자동 전송」, 「실시간 위치」, 「현장 도입 완료」.
   - croScan은 **보완·연동**으로 설명한다. 검토와 정보 정리를 지원할 뿐이고, 전산승인(생산부서 승인권한자)·대면허가(2중점검 Y)·현장 확인은 기존 절차대로 한다.
   - 사람 이름은 쓰지 않고 직책만 쓴다(예: 「현업 멘토(대형 조선소 안전·생산)」, 「현장 안전요원」).
6. **문장은 쉬운 「~합니다」체가 아니라 장표용 명사형·짧은 구로 쓴다.** 문단은 쓰지 않는다. 한 줄은 최대 약 40자다.
